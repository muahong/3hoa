# 3hoa.com

Website tĩnh, phục vụ bằng GitHub Pages (nhánh `main`, thư mục gốc).

- `/` – trang chủ (Classic Arcade Games + liên kết tới game)
- `/math-ninja/` – **Ninja Toán Học**: game chém trái cây học cộng trừ cho bé lớp 1–3 (xem `math-ninja/README.md`)

Cập nhật website: sửa file rồi `git push` lên nhánh `main`, GitHub Pages tự triển khai sau khoảng 1 phút.
